# AGENTS.md

## Проект

Promptik (`promptik`) - desktop speech-to-text приложение для быстрого превращения голоса в готовый промпт для ИИ-чатов. Пользователь запускает запись голосом или горячей клавишей, приложение локально распознает речь через Python ML backend, показывает текст, автоматически копирует его в буфер обмена и сохраняет результат в историю.

Главное правило продукта: аудио и транскрипции не отправляются на внешние серверы. ML-транскрибация выполняется локально.

## Стек

- Desktop: Electron, React, TypeScript, Vite, Tailwind CSS.
- IPC: Electron IPC, contextBridge, globalShortcut, clipboard.
- ML backend: Python 3.11+, faster-whisper, numpy, soundfile.
- Обмен Electron <-> Python: JSON через stdin/stdout child process.

## Команды запуска

- Установка JS-зависимостей: `npm install`
- Установка Python-зависимостей:
  - `cd python`
  - `python -m venv .venv`
  - `.venv\Scripts\activate`
  - `pip install -r requirements.txt`
- Dev-запуск: `npm run dev`
- Windows helper: `run.bat`

## Команды проверки

- TypeScript: `npm run typecheck`
- Production build: `npm run build`
- Python dependency check:
  - `cd python`
  - `.venv\Scripts\python -c "import faster_whisper, numpy, soundfile; print('ok')"`

## Правила кодстайла

- TypeScript strict, без `any` без необходимости.
- React-компоненты небольшие, с явными типами props.
- Electron main process разделен по ответственности: IPC, hotkeys, настройки, файловая система, экспорт, Python bridge.
- Python код с type hints и понятными исключениями.
- UI полностью на русском языке.
- Ошибки должны быть понятны пользователю, без сырых stack trace в интерфейсе.
- Не блокировать UI тяжелыми операциями; транскрибация, экспорт и файловые операции выполняются асинхронно.
- Хранить пользовательские данные в `data/`, временные записи в `temp/`.

## Запреты

- Не заменять рабочую реализацию демо-заглушками.
- Не отправлять аудио, видео или текст транскрипции на внешние серверы.
- Не использовать локальный HTTP-сервер для ML backend, если JSON через stdin/stdout достаточен.
- Не ломать root-папку проекта попыткой переименования из Codex. Если переименование нужно, добавить команду в README.
- Не менять поведение запуска без обновления README.

## Продуктовые требования

- Главный workflow: `Ctrl + Alt + Space` начинает запись, повторное нажатие останавливает запись и запускает локальную транскрибацию.
- После успешной транскрибации текст появляется в UI, выделяется и при включенном auto-copy копируется в буфер обмена.
- Настройка "Формат для ИИ" копирует текст как:

```text
Ответь на следующий голосовой запрос пользователя:

{transcribed_text}
```

- История хранит последние 50 транскрибаций.
- Экспорт не входит в текущий минимальный UI. Не добавлять новые публичные IPC API без UI-сценария и README.
