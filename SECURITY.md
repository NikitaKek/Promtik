# Security Policy

Promptik обрабатывает аудио локально. Пожалуйста, не прикладывайте приватные записи, транскрипции или содержимое `data/history.json` к публичным issue.

## Reporting

Если нашли уязвимость, создайте приватный security advisory в GitHub или свяжитесь с владельцем репозитория напрямую. Не публикуйте exploit details в публичных issue до исправления.

## Scope

- Electron IPC и preload API.
- Python JSON stdin/stdout bridge.
- Обработка локальных аудиофайлов и временных записей.
- Работа с локальными настройками и историей.
